# Contribuire a DynamicForms

Grazie per il tuo interesse nel contribuire! Ecco alcune linee guida:

## Come contribuire

1. Forka il repository e crea un branch per la tua feature o fix.
2. Assicurati che il codice sia formattato e che i test passino (`ng test dynamic-forms`).
3. Apri una pull request descrivendo chiaramente le modifiche.

## Regole di stile
- Segui le convenzioni Angular e TypeScript.
- Scrivi test per ogni nuova funzionalità o bugfix.

## Domande o problemi?
Apri una issue su GitHub!
